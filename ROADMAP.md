# Community Roadmap

The community edition favors small, testable provider contracts over bundled
accounts or hidden services.

## Good First Contributions

- Add structured adapters for additional OpenAI-compatible vision servers.
- Add fixture-based field-image quality scoring without retaining frames.
- Improve speech-recognition aliases while preserving explicit capture intent.
- Add read-only inventory adapters using the generic `InventoryItem` contract.
- Add a local setup validator that reports enabled destinations without secrets.

## Planned

- Front-and-back capture as one bounded transaction.
- Table sweep with explicit left/right prompts and operator-selected close-ups.
- Provider health and latency diagnostics containing no user content.
- Optional authentication for a local operator status page.
- Adapter conformance tests for camera, audio, and display capabilities.

## Out of Scope

- Bundled private storefront or Discord access.
- Automatic purchasing, listing, pricing, or inventory mutation.
- Unprompted continuous camera capture.
- Hidden telemetry, advertising identifiers, or vendor routing.
- Claims of authentication, grading, valuation, or guaranteed identity.
