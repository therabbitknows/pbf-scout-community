# Security Policy

Do not report credentials, private endpoints, or exploitable vulnerabilities in
a public issue. Contact the maintainer through GitHub's private vulnerability
reporting for this repository.

## Supported Versions

Only the latest release receives security updates during the proof-of-concept
stage.

## Scope

High-priority reports include authentication bypass, secret disclosure,
unprompted camera or microphone activation, duplicate publishing, cross-user
data access, and server-side request forgery.
